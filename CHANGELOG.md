# Changelog

All notable changes to freeze-gate are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning follows [SemVer](https://semver.org/).

## [0.2.0] — 2026-07-11

The concept becomes a working reference implementation.

### Added
- **Specification** — [`docs/SPEC.md`](docs/SPEC.md): normative manifest format (v1.0), gate check definitions FG-001…FG-005, verdict and exit-code rules, freeze procedure.
- **JSON Schema** — [`schema/freeze-manifest.schema.json`](schema/freeze-manifest.schema.json) for structural validation of manifests in any toolchain.
- **Python reference implementation** — `src/freeze_gate/`:
  - `manifest.py`: streamed SHA-256 hashing, manifest build/read/write; refuses to freeze empty cores.
  - `verify.py`: the gate — five checks with stable IDs, PASS/WARN/FAIL verdicts.
  - `cli.py`: `freeze-gate freeze | verify | label` with `--strict` mode and honest-label card output.
- **Test suite** — 13 end-to-end tests covering clean freezes, tampered/deleted/stray files, label gaps, malformed manifests, and CLI exit codes.
- **Runnable example** — [`examples/ara-core-example/`](examples/ara-core-example/): a frozen demo core with a passing manifest, generated by the CLI itself.
- **Design notes** — [`docs/NOTES.md`](docs/NOTES.md) 📝 recording rationale and open questions.
- Packaging via `pyproject.toml` with the `freeze-gate` console script.

### Changed
- README rewritten from a one-liner into full project documentation: concept, quickstart, CLI reference, repository layout, spec summary.

## [0.1.0] — initial commit

- Project concept: an Ara-flavored provenance gate for frozen cores with honest labeling and verifiable manifests.
